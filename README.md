# To-Do
Programa de To-dos feito no C++.

#### Projeto de um mini aplicativo de tarefas, desenvolvido totalmente por mim.

### Funções:
- Sistema de Múltiplos Logins
- Criar, editar e apagar to-dos
- Sistema de Histórico
- Sistema de diferencial de texto (Diff)
- Sistema de ADM
- Criar e finalizar to-dos dos outros
- Alterar senha de outros usuários

Foi utilizado Inno Setup Compiler na compilação desse programa.
